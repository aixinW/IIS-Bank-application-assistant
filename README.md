# IIS-Bank-application-assistant
I designed an interactive Figma prototype to improve feedback during online banking applications.

It displays three scenarios: Normal Review, Error Recovery and Uncertain Status.

#Project Status
Implemented: seven Figma screens, navigation and three interaction scenarios.
Simulated: Banking records, document replacement, status decisions and feedback.
Not implemented: Real banking data, document verification.

#Technology Stack
Figma: Interface design and interactive prototyping.
GitHub: Project materials and development documentation.
ChatGPT: Assistance with explanations and documentation.
